## Prompt 1 · Logo assets

You are adding the new Uvalu logo files. `docs/design/logo-consensus-spec.md` is the source of truth. Don't change any app code in this task.

1. Create `assets/logo/` with these SVGs, all on a 64 × 64 grid. Draw the lens first, then the rings stroked on top, using the exact paths and colours from the spec's Geometry and Colour variants sections:
   - `uvalu-mark.svg`: main mark, dark, on a navy `#0D1F3C` tile
   - `uvalu-mark-light.svg`: main mark, light, on a `#F5F7FA` tile
   - `uvalu-mark-mono.svg`: main mark, monochrome, on a white tile
   - `uvalu-mark-small.svg`: small mark, dark, on a navy tile
   - `uvalu-mark-small-mono.svg`: small mark, monochrome
   - `uvalu-lockup-dark.svg`, `uvalu-lockup-light.svg`, `uvalu-lockup-mono.svg`: main mark plus wordmark on a transparent ground

   Tiles: corner radius 22% of the tile size (14 at 64). Scale the mark to 75% of the tile for the main mark and 84% for the small mark, centred.

   Lockup, with H = 64: wordmark "uvalu", Inter 500, font size 56, letter spacing −1.68, starting 12 to the right of the mark, baseline at y ≈ 47 (x-height centred on the mark), final u in mint `#1DD6A4` (dark) or teal `#1A8C6E` (light). Set the viewBox to the outlined artwork plus no padding; clear space is applied by whoever places it.

2. Convert the wordmark to outlines. Add `tools/build_logo.py`, which uses `fontTools` to read Inter Medium (a static `Inter-Medium.ttf` or the variable font at wght 500, downloaded from the official rsms/inter release into `tools/fonts/`, with its OFL licence file), shapes "uvalu" with the −0.03 em tracking, and writes the glyph outlines as `<path>` elements into the three lockups. The script must regenerate every file in `assets/logo/` from the spec values, so nobody edits an SVG by hand. If you can't add `fontTools` as a dev-only dependency, stop and tell me.

3. Raster exports, generated by the same script (use `cairosvg` or `resvg`, dev-only):
   - `favicon.ico` with the small mark at 16, 32 and 48 px (94% of the tile at 16 px, 84% at 32 and 48 px)
   - `uvalu-mark-small-32.png`
   - `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`: main mark tile at 75%
   - `uvalu-mark-512.png`: main mark, dark colours, transparent ground
   - `og-image.png`: dark lockup on navy, 1200 × 630, mark height 120 px, centred

4. Add `tests/test_logo_assets.py`: every file in the spec's asset table exists; each SVG has the spec's ring centres, radii and stroke widths; no SVG contains `<text>`; no light-ground file uses `#1DD6A4`.

5. Reply with the file list and a screenshot or description of the lockups at 24 px and 64 px mark height.

## Prompt 2 · Implementation plan

You are preparing an implementation plan for replacing the old V-stroke logo with the Consensus logo. **Don't change any code in this task.** Write one file: `docs/design/logo-implementation-plan.md`.

Sources of truth, in order: `docs/design/logo-consensus-spec.md`, the lockups in the three mockups (`docs/design/Uvalu.dc.html` top bar, `Uvalu Admin.dc.html` sidebar, `Uvalu.dc.html` and `Uvalu Auth.dc.html` sign-in panel), and the files in `assets/logo/` from prompt 1.

Find every place the old logo or the live-text wordmark is used, at least:
- `app.py` (`page_icon="favicon.svg"`) and the root `favicon.svg`
- `uvalu/shell.py` (top-bar wordmark around line 362, `.uv-logo-tag`)
- `uvalu/styles.py` (`.uv-logo`, `.uv-logo-wordmark`, `.uv-logo-accent`, `.uv-logo-sub`, the comment near line 45)
- `uvalu/authgate.py` (sign-in brand panel, around line 241)
- `uvalu/pages_/admin.py` (admin sidebar wordmark, around line 1572)
- `docs/uvalu-brand-guidelines.md` §3 Logo and the app icon section (V-stroke, base circle, ring), and its favicon row
- `.streamlit/config.toml` and `static/` (static serving currently only exposes `version.json`)
- any inline SVG, test, doc or README that mentions the old mark

For each, give the file and function, what it does now, and what it should do. Then plan small, independently shippable steps (one pull request each, reviewable in under 30 minutes):

- **Favicon:** `page_icon` to `uvalu-mark-small-32.png`. Remove or replace the root `favicon.svg`.
- **Top bar and sidebars:** the lockup as an inline SVG or `<img>` at the mockup sizes: top bar mark height 26 px, gap 13 px to the "value engine" tag; admin sidebar mark height 24 px; dark lockup on dark theme, light lockup on light theme (colours: rings and wordmark `#FFFFFF`/`#0D1F3C`, lens and final u `--logo-accent`). Say whether `st.logo` (Streamlit ≥ 1.35) or the existing custom top bar is the right place, given the app already draws its own top bar.
- **Sign-in:** the dark lockup at a mark height of 48 px on the navy panel, gap 23 px to the tag, in `authgate.py` and any duplicate in the app's sign-in screen.
- **Static files:** how the PNGs and SVGs are served (`static/` with `enableStaticServing`, base64 data URIs, or `st.image`), and whether `.gitignore` needs a change. Recommend one.
- **Brand guidelines:** rewrite §3 Logo and the app icon section from the spec (meaning, two weights, colour table, usage-by-size table, don'ts, "never redraw or recolour a mark by hand" pointing to `assets/logo/`). Bump the guideline version and add a changelog entry.
- **Clean-up:** delete the `.uv-logo-*` classes that become unused; keep the old mark files in git history only.

For each step: why (spec section), files and functions, concrete changes (no code), strings (the `aria-label` "Uvalu" for the logo image, in all six catalogues if it's translatable), tests, how to verify (favicon in light and dark browser themes, top bar in both app themes at 1280 and 920 px, sign-in panel, admin sidebar, side by side with the mockups), size (S/M/L) and dependencies.

End with: open decisions (the spec's three open items: wordmark typeface, light-theme sidebar lockup, final export check), and a `CHANGELOG.md` entry in the existing style. Reply with the path and a 5-line summary.
