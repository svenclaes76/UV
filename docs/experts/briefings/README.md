## Before you send a pack

1. Fill in every **[Sven]** placeholder. Each one is a fact the expert needs and only you know.
2. Check the "Facts checked" list in [../README.md](../README.md). If a fact has changed, update the pack.
3. Export the attachments listed at the end of the pack to PDF, with their version and date visible. Don't send the repo.
4. Leave out the internal first-pass reviews unless you want the expert to react to them. They are useful, but they can anchor the answer. The packs say what they found in neutral terms.
5. Ask for a fixed-fee quote on the questions as listed, before any work starts.
